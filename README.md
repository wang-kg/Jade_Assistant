# 游戏轮换商品助手

## 使用前

- 游戏客户区需为 16:9 且至少 1280×720；识别和点击坐标会从 2560×1440 参考图按客户区尺寸自动缩放。
- 打开游戏商店/轮换商品界面；程序会扫描三个轮换商品位中的目标物品图标。
- 需要安装 Python 3。然后在此目录打开 PowerShell，运行：
  `py -m pip install -r requirements.txt`
- 启动：
  `py game_shop_helper.py`

## 操作

- **F8**：全局开始或暂停，不需要命令行窗口处于焦点。开始前请先点击游戏窗口；若从命令行启动，程序会提示并暂停，不会尝试抢游戏焦点。
- **F9**：全局退出程序。
- 快捷键使用全局键盘钩子并以 Windows 按键轮询作备用，不依赖游戏或命令行处理按键消息；按下 F8/F9 时命令行会显示收到的是钩子事件还是系统按键状态。
- 游戏左下角会显示鼠标穿透的状态提示框，不会遮住点击，也不会修改游戏文件或进程内容。
- 鼠标移到屏幕左上角也会触发安全停止。
- 程序会按游戏标题或 `StarRail` 进程查找崩铁窗口，并只在游戏处于前台时识别和点击，避免把输入发给命令行。
- 若全局键盘钩子无法监听，请让命令行与游戏以相同权限运行；管理员权限的游戏需要管理员命令行启动脚本。
- 在任一轮换商品位找到目标后，程序点击对应商品并检查图标是否消失；若仍存在，会点击右侧招牌商品 **9 次**，再尝试购买一次。
- 若第二次尝试仍未成功，程序会暂停并等待人工检查。
- 购买成功或当前没有目标商品时，程序点击刷新按钮并继续循环。

识别图 `target_template_left.png`、`target_template_mid.png` 和 `target_template_right.png` 分别从你提供的三种商品位置截图中裁出。程序在三个商品位的较大搜索区域内匹配这些模板，因此允许图标位置有少量偏移。坐标会按游戏客户区缩放；若游戏界面布局比例改变，需要重新制作识别图并调整参考坐标。

窗口查找方式、DPI 感知、左下角点击穿透状态层和按下 75ms 后释放的点击方式参考了 [March7thAssistant](https://github.com/moesnow/March7thAssistant)。
