# HSR Currency War Trader

崩坏：星穹铁道「货币战争」轮换商品自动刷新与购买工具。

## 使用须知

- 游戏客户区比例需为 **16:9**，分辨率至少 **1280×720**。
- 使用前请进入游戏内的「货币战争」轮换商品界面。
- 程序需要管理员权限运行，才能在游戏窗口内接收快捷键并执行操作。请以管理员身份打开终端或命令提示符，再启动程序。
- 请保留项目目录中的三个 `target_template_*.png` 图片；它们用于识别目标商品。

## 构建环境

需要安装 **Python 3**。在项目文件夹中打开终端，安装所需依赖：

```powershell
py -m pip install -r requirements.txt
```

## 运行

在项目文件夹中执行：

```powershell
py game_shop_helper.py
```

## 操作

1. 确认游戏停留在轮换商品页面。
2. 按 **F8** 开始或暂停自动操作。
3. 程序会循环刷新商品；发现目标商品后尝试购买。购买未成功时，会点击右侧招牌商品 **9 次**后再次尝试。
4. 按 **F9** 退出程序。鼠标移至屏幕左上角也可触发紧急停止。

程序会在游戏窗口左下角显示当前状态。
